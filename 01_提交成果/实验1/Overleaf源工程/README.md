# 实验1 · XeLaTeX 图片兼容修复版 Overleaf 工程

## 本修复版与上一版的区别

针对XeLaTeX中出现的“Unable to load picture”“not a recognized image format”及随后“Division by 0”，本版让正文的8幅截图统一引用 `assets/*.pdf`，不再让编译器直接读取PNG。每个插图PDF只封装一幅原截图，不使用JPEG压缩；已逐一比较嵌入像素、分辨率和宽高比，均与原始PNG一致。原PNG文件仍保留作为证据，模板、正文及实验结论不变。

2026年10月24日按用户确认将教学周统一为第8周；正文和原始实验证据不变。

本版已使用**原生XeLaTeX（TeX Live 2026 XeTeX 0.999998）连续两遍与原生xdvipdfmx后端**实际生成PDF，不再只以Tectonic结果作为验收。生成结果仍为11页、8幅截图，编译输入记录没有直接读取任何PNG。

请使用本ZIP完整新建Overleaf项目，不要只复制 `main.tex`，因为本版增加了8个PDF插图文件。你原本使用XeLaTeX的设置无需更换。

## 上传与编译

1. 在 Overleaf 中选择 **New Project → Upload Project（上传项目）**，直接上传本 ZIP，无需先解压。
2. 主文件选择根目录的 **`main.tex`**。
3. 在项目设置中将编译器选择为 **XeLaTeX**，使用当前可用的 TeX Live。
4. 重新编译后下载 PDF。ZIP 中的 `preview.pdf` 是本地编译的预览，不是另一份需要编译的源码。

不需要 shell escape、系统字体、自定义脚本或外部图片链接。未代为上传 Overleaf 或课程平台。

**字体说明：**原 DOC 指定宋体、黑体及方正大标宋等专有字体；这些原字库未随模板提供。为了直接在 Overleaf 编译，本工程明确使用 TeX Live 提供的 **Fandol 宋体/黑体**替代，不包含未经授权的字体，也不声称其字形与原专有字库完全相同。纸张、表格尺寸、标题字号和栏目结构按原模板设置。

## 文件结构

- `main.tex`：实验报告正文和个人信息。
- `report-template.sty`：模板尺寸、标题、表格及单元格溢出保护。
- `assets/`：正文引用8幅PDF封装截图；对应PNG和完整原图均保留，PDF中的像素与原PNG完全相同。
- `evidence/`：原始 pcapng、帧详情、导出实体、环境与软件来源记录；`VERIFICATION.md` 是本次重排验证说明。
- `experiment/`：原实验实际使用的 Apache 配置、自建页面与日志，作为实验材料保留，不参与 LaTeX 编译。
- `preview.pdf`：本地原生XeLaTeX实际编译的11页预览。

正文中的原部署目录指2026年10月13日实验发生时的实际路径，并非要求在 Overleaf 上部署服务器。`experiment/httpd.conf` 记录了当次机器的绝对运行路径，不能原样拿到其他机器启动；这不影响报告编译。

## 修改提示

单元格会测量内容实际高度；如果编辑后超出该栏，编译将报 `Cell overflows on page ...`，而不会裁掉或缩小正文。应把多出的内容移入接上页，不要删除高度保护。

正文保留了部分长URL和协议字段，TeX日志中可能出现 `Underfull \hbox`，是窄栏内折行或行间空隙的提示；不能据此推断文字被裁剪。验证说明列出本次实际检查结果。
