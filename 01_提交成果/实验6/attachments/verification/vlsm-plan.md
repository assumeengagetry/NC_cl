## 配置建议
以下仅配置编址；题3评分为24项（12接口×IP与掩码），活动未要求启用、时钟或跨网段路由。可按实际任务选择是否no shutdown，不能把未配置或未测通写成成功。

### Router4

```text
enable
configure terminal
interface Fa0/0
ip address 192.168.1.1 255.255.255.192
interface Fa0/1
ip address 192.168.1.65 255.255.255.192
interface S0/0/0
ip address 192.168.1.225 255.255.255.252
interface S0/0/1
ip address 192.168.1.229 255.255.255.252
end
show running-config
```
