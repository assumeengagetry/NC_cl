# 题4 VLSM规划（按实际评分确定同容量LAN对应关系）

父块172.16.64.0/21，范围172.16.64.0至172.16.71.255，共2048地址。按容量从大到小划分；同容量LAN的块对应关系以本次活动评分核对结果确定，各接口使用所属子网的首个可用地址。

占用2×512+2×256+2×128+3×4=1804；剩余2048−1804=244，范围172.16.71.12至172.16.71.255。250主机最小/24需256总地址，余量不足，且最后一个/24（71.0/24）前三个/30已经占用，保持分配无法新增。

按地址从低到高的第一个/23为172.16.64.0/23（本方案LAN B），广播172.16.65.255。第三字节从64（01000000）到65（01000001）；掩码第三字节254（11111110），网络边界为偶数。写172.16.65.0/23不是新网络边界，会被严格检查拒绝或被规范为64.0/23，造成重复/重叠。

## HQ

```text
enable
configure terminal
interface Fa0/0
ip address 172.16.66.1 255.255.254.0
no shutdown
interface Fa0/1
ip address 172.16.64.1 255.255.254.0
no shutdown
interface S0/0/0
ip address 172.16.71.1 255.255.255.252
no shutdown
interface S0/2/0
ip address 172.16.71.5 255.255.255.252
clock rate 64000
no shutdown
interface S0/0/1
ip address 172.16.71.9 255.255.255.252
no shutdown
end
show running-config
```
