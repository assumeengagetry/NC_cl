# 本次实验的验证依据

验证日期：2026-10-13。

## 实验操作

- Apache 独立配置实际执行 `httpd -f <配置路径> -t`，输出 `Syntax OK`。
- 本机 TCP 监听为 `127.0.0.1:8086`；真实 Chromium 窗口访问根路径成功，另用真实 HTTP 请求核对200状态、Apache响应标识及首页必要内容。
- dumpcap 权限问题在用户加入 wireshark 组后解决，在新组会话成功枚举本机接口并捕获实验流量。
- 原始 pcapng 包含38帧，TShark识别10个HTTP帧，只有实验服务器TCP80流量。
- file1目标请求/响应是帧8/12，file2首次是20/23，普通刷新是28/29。
- 真实响应实体导出为128字节和371字节；第二次file2响应为304，没有正文，也没有补造Content-Length字段。
- 软件来源与签名验证详见 `software-provenance.txt`，每个下载的运行软件包均通过本机Arch公钥环独立验证。

## 排版验证

- 使用 Tectonic 0.17.0（基于XeTeX）实际编译，退出码0，PDF为13页A4。
- 已对首次编译的中文路径缺字、数学环境中的中文句号和双截图页溢出建立失败验收，修复后相关验收通过。
- 最终编译没有 Missing character、Overfull 或重复页面锚点警告；少量 Underfull hbox 是窄表格/长字段折行的非致命排版提示，不代表内容越界。
- 初次文本坐标检查只验证纸张安全范围，不足以证明内容没有跨越模板底框；独立复核发现自建首页页的流程图、汇总页的末段文字仍有栏内越界。
- 针对这两处问题新增实际表格边界验收：从最终PDF矢量路径识别底框，将文本及图内文字的坐标与真实边界比较。新增验收在旧版上明确失败，修订后全部内容页通过。
- LaTeX现直接测量每个内容页的自然高度，要求不超过235 mm，在237 mm栏目内保留余量；超出即报编译错误，而不是静默遮挡。该保护在未缩减旧版图2前实际拒绝编译，修订后10个内容页全部通过。
- 重新渲染检查了修订的自建首页页、汇总页和配置解释页；流程图、末段及配置说明现均位于表格内。
- 指令解释已明确区分：Require all granted负责访问授权，Options -Indexes关闭目录索引，AllowOverride None禁止.htaccess覆盖，未修改实际服务器配置。
- 独立复核没有发现任务2十问或任务3四问缺失，也没有发现所读HTTP数据与正文冲突。最终仍需以原始pcap和本机实际验证为依据，不能把复核报告当成重新实验的证明。
